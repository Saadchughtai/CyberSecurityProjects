# Network Traffic Analysis

## About This Section

This section contains my learning and practical exercises on network traffic analysis through TryHackMe.

I am learning how to use different tools to capture and analyse network traffic, understand how devices communicate and identify anything unusual that could indicate a security issue.

## What I Am Learning

- How network traffic works and how it can be analysed.
- How to capture and inspect network packets.
- How to use Wireshark to investigate network traffic.
- How to apply filters to find specific packets.
- How to analyse PCAP files.
- How to identify unusual network activity.
- How to use NetworkMiner for basic network forensics.
