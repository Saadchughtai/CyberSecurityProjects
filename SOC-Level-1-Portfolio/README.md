## Investigation Approach

My practical SOC investigations focus on:

1. **Alert Identification** — Understanding the security event or suspicious activity.
2. **Evidence Collection** — Reviewing relevant logs, network traffic, or security artefacts.
3. **Threat Analysis** — Investigating suspicious indicators and correlating evidence.
4. **Classification** — Assessing whether an alert is a true positive, false positive, or inconclusive.
5. **Documentation & Escalation** — Recording findings and recommending appropriate response actions.
